# RAG: Ollama vs Cloud

## Охват

Финальный прогон `artifacts/rag-bench-full2.log` был прерван пользователем.
Полностью завершены 10 из 12 вопросов для `ollama` (30 попыток) и 9 из 12
для `cloud` (27 попыток). Недопрогнанные вопросы и повторы в сводку не
включены. `--quick` был выполнен отдельно: 5 вопросов, 1 повтор.

Retrieval выполнялся один раз на вопрос, rewrite был выключен. Оба профиля
получали одинаковые подготовленные чанки.

## Выводы

- Cloud чаще получил `ok`, но оставался медленнее и нестабильнее на этой
  частично завершённой выборке.
- Медиана генерации: ollama 12.230 с против cloud 43.224 с; p95:
  34.313 с против 186.493 с. Retrieval сопоставим.
- Стабильность завершённых вопросов: ollama 70%, cloud 44.44%.
- У 3B частая проблема — правильные числовые факты без цитаты требуемой
  структурой; это видно по `unverified`.

## Ограничения

- Прогон прерван пользователем: ollama 10/12, cloud 9/12; недостающие
  вопросы не включены.
- Малая выборка.
- Факты проверяются регистронезависимыми подстроками; морфология не
  нормализуется.
- Нет LLM-судьи; `UNVERIFIED` смешивает ошибку формата ответа с
  недостаточной строгостью структурной проверки цитат.
- Причины отдельных cloud-задержек 54/17 с в имеющемся логе не видны.
- `completion_tokens` для `full2` не выводились.
- Отдельный прямой вызов модели на no-answer после остановки не выполнялся.
